# poinstool

เครื่องมือสำหรับ dev ใช้มาร์คจุดในเกม พร้อมวงรัศมีบอกขนาด แก้ไขจุดทีหลังได้ และส่งออกเป็น `vec3` / `vec4` ไปวางใน config

- ทำงานฝั่ง client อย่างเดียว ไม่มี server script ไม่ใช้ฐานข้อมูล
- จุดเก็บใน KVP ของ client (`SetResourceKvp`) อยู่ครบหลังรีสตาร์ท resource หรือออกเข้าเซิร์ฟใหม่ แต่เป็นของเครื่องใครเครื่องมัน
- ต้องมี `ox_lib`
- ไม่ได้อยู่บน git เป็นเครื่องมือสำหรับเซิร์ฟ dev อย่าเอาขึ้นเซิร์ฟจริง (ทุกคนที่มี resource นี้วาร์ปไปจุดที่ตัวเองมาร์คได้)

## วิธีใช้

| ปุ่ม (ค่าเริ่มต้น) | ทำอะไร |
|---|---|
| `J` | มาร์คจุดตรงที่ยืนอยู่ทันที ใช้รัศมีเริ่มต้นจาก `Config.Radius.default` |
| `F7` | เปิดรายการจุด (มีเมาส์) |
| `Esc` หรือ `F7` อีกครั้ง | ปิดรายการ |

ผู้เล่นเปลี่ยนปุ่มเองได้ที่ Settings → Key Bindings → FiveM (คำอธิบายเป็นภาษาอังกฤษ เพราะเมนูของเกมแสดงภาษาไทยไม่ได้)

ในเกมแต่ละจุดจะมี
- วงทรงกระบอกบนพื้น กว้างเท่ารัศมี × 2
- เส้นตั้งจากพื้นถึงตำแหน่งจริงของจุด และจุดเล็กตรงตำแหน่งนั้น
- เส้นแนวนอนชี้ทิศที่หันหน้า (heading ที่จะออกไปใน `vec4`)
- ป้าย `#ลำดับ  รัศมีm` และชื่อจุดถ้าเป็นภาษาอังกฤษ (ฟอนต์ของเกมไม่มีภาษาไทย ชื่อภาษาไทยจึงเห็นได้เฉพาะใน UI)

จุดที่เลือกอยู่ในรายการจะสว่างกว่าจุดอื่น วาดเฉพาะจุดที่อยู่ในระยะ `Config.Draw.distance` + รัศมีของจุดนั้น (ใช้ `lib.points` ไม่มี loop วัดระยะเอง)

### หน้ารายการ

- คลิกแถวเพื่อเลือกจุด คลิกซ้ำเพื่อยกเลิกการเลือก
- แก้ชื่อ รัศมี ทิศที่หัน และ X / Y / Z ได้ วงในเกมเปลี่ยนตามทันที
- ช่องตัวเลข: พิมพ์ได้เลย หรือกดลูกศรขึ้น/ลง (`Shift` = ×10, `Alt` = ÷10)
- ช่อง **Z** ใช้ scroll เมาส์ได้ scroll ขึ้น = +0.5, scroll ลง = −0.5 บวกลบจากค่าเดิมตรง ๆ ไม่ปัดเศษ (30.09 → 30.59) วาง prop แล้วไล่ความสูงได้เร็ว
- ทิศที่หันหน้าหมุนได้ที่วงกลม (หน้าปัด) ทางซ้ายของช่องชื่อ ได้ค่าเป็นองศาเต็มเสมอ ถ้าต้องการทศนิยมให้พิมพ์ในช่อง **หันหน้า**
  - กดค้างแล้วลาก: เข็มชี้ตามเมาส์ (บน = 0 / N, ซ้าย = 90, ล่าง = 180, ขวา = 270 ตาม heading ของ GTA)
  - scroll ขึ้น = +1°, scroll ลง = −1° ถ้าค่าเดิมมีทศนิยม scroll ครั้งแรกจะปัดไปองศาเต็มถัดไปในทิศนั้น (321.25 → ขึ้น 322 / ลง 321)
  - คลิกที่หน้าปัดแล้วใช้ลูกศรได้ (ขึ้น/ซ้าย = +1°, ลง/ขวา = −1°)
- ไม้บรรทัดรัศมีเป็นสเกล log ช่วงค่าน้อยละเอียด ช่วงค่ามากหยาบขึ้น (ถึง 5 m ขยับทีละ `step`, ถึง 20 m ทีละ 0.5, ถึง 100 m ทีละ 1, เกินนั้นทีละ 5)
- **ย้ายมาตรงที่ยืน** เอาตำแหน่งและทิศปัจจุบันของตัวเองไปแทนจุดนั้น (รัศมี ชื่อ prop และ blip คงเดิม)
- **ติดพื้น** เปลี่ยน Z ของจุดเป็นระดับพื้นใต้จุด (หาพื้นจาก Z + 0.5 ลงไป) ใช้ตอนวาง prop เพราะ Z จากการกด J เป็นระดับเอวของตัวละคร สูงจากพื้นประมาณ 1 m ต้องอยู่ใกล้จุดพอให้เกมโหลดพื้นแล้ว ไม่งั้นจะขึ้นว่าหาพื้นไม่เจอ
- **วาร์ปไปจุดนี้** ปิดรายการแล้ววาร์ปไปจุดนั้น
- **ลบจุด** ต้องกดสองครั้งภายใน 3 วินาที ลำดับจุดที่อยู่หลังจะเลื่อนขึ้นมา
- ปุ่ม vec3 / vec4 คัดลอกค่าของจุดนั้นลง clipboard
- แถวในรายการมีป้าย `prop` / `blip` บอกว่าจุดนั้นมี prop หรือ blip

### Prop

พิมพ์ชื่อโมเดลในช่อง **Prop** แล้วกด `Enter` (หรือคลิกออกจากช่อง) เพื่อวาง prop ที่จุดนั้น ลบชื่อให้ว่างแล้วกด `Enter` เพื่อเอา prop ออก

- พิมพ์ได้เฉพาะ `a-z A-Z 0-9 _ -` ยาวไม่เกิน `Config.Prop.length`
- โมเดลต้องมีในเกม (`IsModelInCdimage`) และต้องไม่ใช่รถหรือ ped ถ้าใช้ไม่ได้ ช่องจะเป็นเส้นประ ขีดฆ่าชื่อ และขึ้นข้อความว่าไม่พบโมเดล
- prop วางที่พิกัดของจุดตรง ๆ (`CreateObjectNoOffset`) หันตามทิศของจุด ตรึงไว้กับที่ ไม่ได้ snap ลงพื้นให้เอง ถ้าลอยให้กด **ติดพื้น** หรือปรับ Z เอง
- prop เป็น object ฝั่ง client เห็นคนเดียว ไม่ sync ให้คนอื่น เกิดตอนเข้าใกล้จุด (ระยะเดียวกับวง) และหายตอนออกห่าง ซ่อนวง หรือหยุด resource
- แก้ X / Y / Z / ทิศ แล้ว prop ขยับตามทันที

### Blip

ส่วน **แผนที่** ในหน้าแก้ไขจุด

- **Blip** แสดงไอคอนบนแผนที่ ตั้ง **ไอคอน** (sprite id), **สี** (blip colour id) และ **ขนาด** ได้ ดูเลข sprite / สีได้ที่ https://docs.fivem.net/docs/game-references/blips/
- **วงรัศมีบนแผนที่** วาดวงตามรัศมีของจุดบนแผนที่ ใช้สีเดียวกับ blip เปิดอย่างเดียวโดยไม่มีไอคอนก็ได้
- ชื่อ blip ใช้ชื่อจุดถ้าเป็นภาษาอังกฤษ ถ้าไม่มีชื่อหรือเป็นภาษาไทยจะใช้ `Point #ลำดับ` (เกมแสดงภาษาไทยในแผนที่ไม่ได้)
- blip เห็นคนเดียว แสดงพร้อมวง (ซ่อนวงแล้ว blip หายด้วย)

### หน้าส่งออก

เลือกรูปแบบแล้วกด **คัดลอกทั้งหมด** ได้ข้อความเยื้อง 4 ช่อง มี comma ท้ายบรรทัด วางลงใน table ของ config ได้เลย

| ตัวเลือก | ผลลัพธ์ต่อ 1 จุด |
|---|---|
| vec3 | `vec3(195.17, -933.77, 30.69),` |
| vec4 | `vec4(195.17, -933.77, 30.69, 144.50),` |
| + ใส่รัศมี | `{ coords = vec3(...), radius = 2.00 },` |
| + ใส่ชื่อ | `{ label = 'ชื่อ', coords = vec3(...), radius = 2.00 },` (จุดที่ไม่มีชื่อจะไม่มี `label`) |
| + ใส่โมเดล | ``{ coords = vec3(...), model = `prop_bench_01a` },`` (เฉพาะจุดที่มี prop) |
| + ใส่ blip | `{ coords = vec3(...), blip = { sprite = 280, color = 5, scale = 0.80 } },` (เฉพาะจุดที่เปิด blip หรือวงบนแผนที่) |

ใน `blip = { ... }`
- `sprite` และ `scale` มีเฉพาะจุดที่เปิด **Blip**
- `color` มีเสมอ
- `area = true` มีเฉพาะจุดที่เปิด **วงรัศมีบนแผนที่** เช่นเปิดแค่วง จะได้ `blip = { color = 1, area = true }`

ลำดับ field ในแต่ละบรรทัด: `label`, `coords`, `radius`, `model`, `blip` ถ้าไม่ได้เลือกอะไรเพิ่มหรือจุดนั้นไม่มีค่าที่เลือก จะได้แค่ `vec3(...)` / `vec4(...)`

`'` และ `\` ในชื่อจะถูก escape ให้เป็น string ของ Lua ที่ถูกต้อง โมเดลออกมาเป็น backtick hash ตามแบบ config ของเรา ตัวเลือกที่เลือกไว้จำไว้ในเครื่อง (localStorage ของ NUI) ค่าเริ่มต้นคือ vec3 + ใส่รัศมี + ใส่โมเดล

**ล้างทั้งหมด** ต้องกดสองครั้ง ลบจุดทุกจุดรวมถึงใน KVP

## Build UI

UI อยู่ใน `ui_src/` (Vite + Svelte 5) build ออกไปที่ `web/build/` ต้อง build ก่อน start resource

```bash
cd ui_src
bun install
bun run build
```

`bun run dev` เปิดหน้าทดสอบที่ `http://localhost:5249` พร้อมข้อมูลตัวอย่าง กด `J` = จำลองการเพิ่มจุด, `` ` `` = เปิดรายการ, `9` = แจ้งเตือนจุดเต็ม, `0` = ล้างรายการ

## NUI contract

Lua → UI (`{ action, payload }`)

| action | payload |
|---|---|
| `hydrate` | `{ scale, locale, keys = { add, menu }, precision, radius = { default, min, max, step }, limit, labelLength, modelLength, blip = { spriteMax, colorMax, scaleMin, scaleMax }, visible, points }` |
| `open` | `{ keys }` |
| `close` | – |
| `add` | `{ index, point, keys }` |
| `full` | – |
| `visible` | `boolean` |

`point` = `{ x, y, z, h, r, label, model, blip, sprite, color, scale, area }`

UI → Lua (ตอบ `1` / `0` ทุกครั้ง)

- `uiReady`, `close`, `clear`
- `select { index }` (0 = ไม่เลือก), `visible { value }`
- `update { index, x, y, z, h, r, label, blip, sprite, color, scale, area }`
- `model { index, model }` (`''` = เอา prop ออก)
- `here { index }` และ `ground { index }` ตอบเป็น `point` ที่แก้แล้ว
- `teleport { index }`, `remove { index }`

KVP `points` เก็บเป็น JSON array ของแถว `[x, y, z, heading, radius, label, model, blip, sprite, color, scale, area]` แถวจากเวอร์ชันแรกที่มีแค่ 6 ช่องยังโหลดได้ (ไม่มี prop / blip)
