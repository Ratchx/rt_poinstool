# poinstool

เครื่องมือสำหรับ dev ใช้มาร์คจุดในเกม พร้อมวงรัศมีบอกขนาด แก้ไขจุดทีหลังได้ และส่งออกเป็น `vec3` / `vec4` ไปวางใน config

- ทำงานฝั่ง client อย่างเดียว ไม่มี server script ไม่ใช้ฐานข้อมูล
- จุดเก็บใน KVP ของ client (`SetResourceKvp`) อยู่ครบหลังรีสตาร์ท resource หรือออกเข้าเซิร์ฟใหม่ แต่เป็นของเครื่องใครเครื่องมัน
- ต้องมี `ox_lib`
- ไม่ได้อยู่บน git เป็นเครื่องมือสำหรับเซิร์ฟ dev อย่าเอาขึ้นเซิร์ฟจริง (ทุกคนที่มี resource นี้วาร์ปไปจุดที่ตัวเองมาร์คได้)

## วิธีใช้

| ปุ่ม (ค่าเริ่มต้น) | ทำอะไร |
|---|---|
| `J` | มาร์คจุดตรงที่ยืนอยู่ทันที ใช้รัศมีเริ่มต้นจาก `Config.Radius.default` |
| `F7` | เปิดรายการจุด (มีเมาส์) |
| `Esc` หรือ `F7` อีกครั้ง | ปิดรายการ |
| `K` | เปิด/ปิดโหมดวางด้วยเมาส์ (ดูหัวข้อด้านล่าง) |
| `Backspace` | ย้อนการวางล่าสุดในโหมดวางด้วยเมาส์ |

ผู้เล่นเปลี่ยนปุ่มเองได้ที่ Settings → Key Bindings → FiveM (คำอธิบายเป็นภาษาอังกฤษ เพราะเมนูของเกมแสดงภาษาไทยไม่ได้)

ในเกมแต่ละจุดจะมี
- วงแหวนเส้นบาง ๆ บนพื้นตามรัศมีของจุด (บอกระยะ)
- marker ทรงกระบอกบนพื้น ขนาด X / Y / Z และสีตั้งแยกได้ทุกจุด (ไม่ผูกกับรัศมี)
- เส้นตั้งจากพื้นถึงตำแหน่งจริงของจุด และจุดเล็กตรงตำแหน่งนั้น
- ลูกศรแนวนอนชี้ทิศที่หันหน้า (heading ที่จะออกไปใน `vec4`) หัวลูกศรคือด้านหน้า เป็นแกน +Y ของ entity แกนเดียวกับที่ `SetEntityHeading` ใช้ จุดที่กด J ลูกศรจะชี้ไปทางที่ตัวละครหันอยู่ตอนกด
- ป้าย `#ลำดับ  รัศมีm` และชื่อจุดถ้าเป็นภาษาอังกฤษ (ฟอนต์ของเกมไม่มีภาษาไทย ชื่อภาษาไทยจึงเห็นได้เฉพาะใน UI)

วงแหวนของจุดที่เลือกอยู่ในรายการจะเป็นสีขาวเต็ม จุดอื่นจะจางกว่า วาดเฉพาะจุดที่อยู่ในระยะ `Config.Draw.distance` + รัศมีของจุดนั้น (ใช้ `lib.points` ไม่มี loop วัดระยะเอง)

### หน้ารายการ

- คลิกแถวเพื่อเลือกจุด คลิกซ้ำเพื่อยกเลิกการเลือก
- แก้ชื่อ รัศมี ทิศที่หัน และ X / Y / Z ได้ วงในเกมเปลี่ยนตามทันที
- ช่องตัวเลข: พิมพ์ได้เลย หรือกดลูกศรขึ้น/ลง (`Shift` = ×10, `Alt` = ÷10)
- ช่อง **Z** ใช้ scroll เมาส์ได้ scroll ขึ้น = +0.5, scroll ลง = −0.5 บวกลบจากค่าเดิมตรง ๆ ไม่ปัดเศษ (30.09 → 30.59) วาง prop แล้วไล่ความสูงได้เร็ว
- ทิศที่หันหน้าหมุนได้ที่วงกลม (หน้าปัด) ทางซ้ายของช่องชื่อ ได้ค่าเป็นองศาเต็มเสมอ ถ้าต้องการทศนิยมให้พิมพ์ในช่อง **หันหน้า**
  - กดค้างแล้วลาก: เข็มชี้ตามเมาส์ (บน = 0 / N, ซ้าย = 90, ล่าง = 180, ขวา = 270 ตาม heading ของ GTA)
  - scroll ขึ้น = +1°, scroll ลง = −1° ถ้าค่าเดิมมีทศนิยม scroll ครั้งแรกจะปัดไปองศาเต็มถัดไปในทิศนั้น (321.25 → ขึ้น 322 / ลง 321)
  - คลิกที่หน้าปัดแล้วใช้ลูกศรได้ (ขึ้น/ซ้าย = +1°, ลง/ขวา = −1°)
- ไม้บรรทัดรัศมีเป็นสเกล log ช่วงค่าน้อยละเอียด ช่วงค่ามากหยาบขึ้น (ถึง 5 m ขยับทีละ `step`, ถึง 20 m ทีละ 0.5, ถึง 100 m ทีละ 1, เกินนั้นทีละ 5)
- **ย้ายมาตรงที่ยืน** เอาตำแหน่งและทิศปัจจุบันของตัวเองไปแทนจุดนั้น (รัศมี ชื่อ prop และ blip คงเดิม)
- **ติดพื้น** เปลี่ยน Z ของจุดเป็นระดับพื้นใต้จุด (หาพื้นจาก Z + 0.5 ลงไป) ใช้ตอนวาง prop เพราะ Z จากการกด J เป็นระดับเอวของตัวละคร สูงจากพื้นประมาณ 1 m ต้องอยู่ใกล้จุดพอให้เกมโหลดพื้นแล้ว ไม่งั้นจะขึ้นว่าหาพื้นไม่เจอ
- **วาร์ปไปจุดนี้** ปิดรายการแล้ววาร์ปไปจุดนั้น
- **ลบจุด** ต้องกดสองครั้งภายใน 3 วินาที ลำดับจุดที่อยู่หลังจะเลื่อนขึ้นมา
- **ลบหลายจุดทีเดียว**: ติ๊กช่องสี่เหลี่ยมหน้าแถวที่ต้องการ
  - `Shift` + คลิก (ที่ช่องติ๊กหรือที่แถว) = เลือกเป็นช่วงจากจุดที่ติ๊กล่าสุด
  - `Ctrl` + คลิกที่แถว = ติ๊ก/เอาติ๊กออกโดยไม่เปิดหน้าแก้ไข
  - พอมีจุดถูกติ๊ก จะมีแถบด้านล่างรายการ: **เลือกทั้งหมด**, **ยกเลิก**, **ลบ N จุด** (กดสองครั้งเพื่อยืนยัน) และหน้าแก้ไขจุดจะซ่อนไว้ก่อนจนกว่าจะยกเลิกหรือลบเสร็จ
  - ลบแล้ว prop / blip ของจุดเหล่านั้นหายไปด้วย จุดที่เหลือเลื่อนลำดับขึ้นมาเหมือนการลบทีละจุด
- ปุ่ม vec3 / vec4 คัดลอกค่าของจุดนั้นลง clipboard
- แถวในรายการมีป้าย `prop` / `blip` บอกว่าจุดนั้นมี prop หรือ blip

### Marker

ส่วน **Marker** ในหน้าแก้ไขจุด ตั้งหน้าตา marker ที่วาดบนพื้นของแต่ละจุด

- **X / Y / Z** = ขนาด marker (กว้าง / ยาว / สูง เป็นเมตร) พิมพ์ได้ กดลูกศรได้ หรือ scroll เมาส์ทีละ ±0.1 ค่าอยู่ในช่วง `Config.Marker.size_min`–`size_max`
- **X = Y** ติ๊กไว้ แก้ X หรือ Y ช่องเดียว อีกช่องจะเปลี่ยนตาม (ติ๊กให้เองถ้า X กับ Y เท่ากันอยู่แล้ว)
- **เท่ารัศมี** ตั้ง X และ Y = รัศมี × 2 ให้ marker กว้างพอดีวงแหวน
- **สี** พิมพ์ hex เช่น `#FF3B30` หรือกดสีสำเร็จรูปด้านล่าง ช่อง **A** = ความทึบ 0–255 (scroll ทีละ ±5, 0 = ไม่วาด marker) กล่องซ้ายสุดแสดงสีจริงทั้งแบบโปร่งและทึบ
- จุดใหม่ใช้ขนาดและสีจาก `Config.Marker.size` / `Config.Marker.color`

### Prop

พิมพ์ชื่อโมเดลในช่อง **Prop** แล้วกด `Enter` (หรือคลิกออกจากช่อง) เพื่อวาง prop ที่จุดนั้น ลบชื่อให้ว่างแล้วกด `Enter` เพื่อเอา prop ออก

- พิมพ์ได้เฉพาะ `a-z A-Z 0-9 _ -` ยาวไม่เกิน `Config.Prop.length`
- โมเดลต้องมีในเกม (`IsModelInCdimage`) และต้องไม่ใช่รถหรือ ped ถ้าใช้ไม่ได้ ช่องจะเป็นเส้นประ ขีดฆ่าชื่อ และขึ้นข้อความว่าไม่พบโมเดล
- prop วางที่พิกัดของจุดตรง ๆ (`CreateObjectNoOffset`) หันตามทิศของจุด (`SetEntityRotation(prop, 0, 0, heading)` ตั้งตรงเสมอ) ตรึงไว้กับที่ ไม่ได้ snap ลงพื้นให้เอง ถ้าลอยให้กด **ติดพื้น** หรือปรับ Z เอง
- โมเดล prop แต่ละตัวทำด้านหน้าไว้ไม่เหมือนกัน บางตัวด้านหน้าอยู่ฝั่ง +Y ตรงกับลูกศร บางตัวหันไปทางอื่น ถ้า prop ดูหันไม่ตรงลูกศร ให้หมุนทิศจนตัว prop หันถูก ค่า heading ที่ได้จะใช้ใน script ได้ตรงเพราะ script ก็หมุน prop ด้วยค่าเดียวกัน
- prop เป็น object ฝั่ง client เห็นคนเดียว ไม่ sync ให้คนอื่น เกิดตอนเข้าใกล้จุด (ระยะเดียวกับวง) และหายตอนออกห่าง ซ่อนวง หรือหยุด resource
- แก้ X / Y / Z / ทิศ แล้ว prop ขยับตามทันที

### Blip

ส่วน **แผนที่** ในหน้าแก้ไขจุด

- **Blip** แสดงไอคอนบนแผนที่ ตั้ง **ไอคอน** (sprite id), **สี** (blip colour id) และ **ขนาด** ได้ ดูเลข sprite / สีได้ที่ https://docs.fivem.net/docs/game-references/blips/
- **วงรัศมีบนแผนที่** วาดวงตามรัศมีของจุดบนแผนที่ ใช้สีเดียวกับ blip เปิดอย่างเดียวโดยไม่มีไอคอนก็ได้
- ชื่อ blip ใช้ชื่อจุดถ้าเป็นภาษาอังกฤษ ถ้าไม่มีชื่อหรือเป็นภาษาไทยจะใช้ `Point #ลำดับ` (เกมแสดงภาษาไทยในแผนที่ไม่ได้)
- blip เห็นคนเดียว แสดงพร้อมวง (ซ่อนวงแล้ว blip หายด้วย)

### โหมดวางด้วยเมาส์

กด `K` (หรือปุ่ม **วางด้วยเมาส์** ในหน้า Poly) เพื่อคลิกวางบนพื้นแทนการเดินไปยืน ใช้ได้ทั้งตอนเดินปกติและตอน noclip

- มีเคอร์เซอร์ค้างบนจอ ชี้ที่พื้นหรือ object แล้วจะมีเส้นตั้งกับจุดเล็กบอกตำแหน่งที่จะวาง (ยิงแสงจากกล้องผ่านเคอร์เซอร์ ไกลสุด `Config.Place.distance`)
- **คลิกซ้าย** = วาง ชี้ไปที่ฟ้าหรือที่ว่างจะไม่วางและขึ้นข้อความบอก
- **ค้างคลิกขวา** = เคอร์เซอร์หาย หมุนกล้องได้ตามปกติ ปล่อยแล้วเคอร์เซอร์กลับมา ระหว่างโหมดนี้ยิง/เล็งอาวุธไม่ได้
- `Backspace` = ย้อนสิ่งที่วางล่าสุด (ย้อนได้เฉพาะที่วางในรอบนี้ ทีละอัน)
- `K` อีกครั้ง หรือ `Esc` = ออกจากโหมด กด `F7` เปิดรายการก็ออกจากโหมดให้เอง
- จะวางอะไรขึ้นกับหน้าที่เลือกไว้ล่าสุด กล่องมุมขวาบนบอกไว้ตลอด:
  - เลือก Poly ไว้ในแท็บ Poly → คลิกแต่ละครั้งเพิ่มจุดยอดต่อท้าย Poly นั้น มีเส้นประจากจุดยอดสุดท้ายมาที่เคอร์เซอร์ และจากเคอร์เซอร์ไปจุดยอดแรก ให้เห็นรูปก่อนคลิก
  - นอกนั้น → คลิกแต่ละครั้งเพิ่มจุดใหม่ในรายการจุด ตำแหน่ง = พื้นที่คลิก + `Config.Place.point_lift` (ค่าเริ่มต้น 1 m เท่าระดับเอวตอนกด J) หันหน้าเข้าหากล้อง (ลูกศรชี้กลับมาหาคนวาง) ปัดเป็นองศาเต็ม
- เปิดโหมดแล้ววงจะแสดงเองถ้าซ่อนอยู่

### Poly

แท็บ **Poly** สร้างโซน poly แบบ `lib.zones.poly` ของ ox_lib ได้หลายอัน แยกจากรายการจุด

- **สร้าง Poly** แล้วกด **วางด้วยเมาส์** คลิกวางจุดยอดเรียงรอบพื้นที่ (ลำดับจุดยอด = ลำดับที่คลิก) ครบแล้วกด `K` หรือ `Esc`
- ในเกม Poly วาดเป็นกำแพงโปร่งแบบเดียวกับ debug ของ ox_lib สูง = **ความหนา** โดยมี Z ของแต่ละจุดยอดอยู่กลางกำแพง พร้อมเลขจุดยอด จุดยอดที่เลือกในรายการจะเป็นจุดใหญ่สีขาว
- **ชื่อ** / **ความหนา** (scroll ทีละ ±0.5) / **สี** ของกำแพง แก้ได้และเห็นผลทันที
- รายการจุดยอด: คลิกเลือกแล้วแก้ X / Y / Z ได้ (ช่อง Z scroll ทีละ ±0.5) หรือกด **ลบจุดยอด**
- **เกลี่ย Z** ตั้ง Z ทุกจุดยอดให้เท่ากับค่าเฉลี่ย ox_lib ทำ poly ที่ Z ไม่เท่ากันให้แบนเองตอนสร้างโซน กดก่อนส่งออกจะได้เห็นรูปเหมือนตอนใช้จริง
- **คัดลอก** = คัดลอก Poly นี้อันเดียว (มีชื่อถ้าตั้งไว้)
- **ลบ Poly** กดสองครั้งเพื่อยืนยัน
- จำนวนสูงสุด `Config.Poly.limit` อัน อันละไม่เกิน `Config.Poly.vertices` จุดยอด Poly เก็บใน KVP ของ client เหมือนรายการจุด

### หน้าส่งออก

ด้านบนเลือกได้ว่าจะส่งออก **จุด** หรือ **Poly**

**Poly** ได้ทีละก้อนแบบนี้ (Poly ที่ยังไม่มีจุดยอดจะไม่ออกมา ติ๊ก **ใส่ชื่อ** เพื่อใส่ `label`)

```lua
    {
        label = 'ลานจอดรถ',
        points = {
            vec3(-1593.12, -1047.66, 13.02),
            vec3(-1571.40, -1032.18, 13.02),
            vec3(-1560.88, -1049.25, 13.40),
        },
        thickness = 6.00,
    },
```

ใช้กับ ox_lib ได้ตรง ๆ เช่น `lib.zones.poly({ points = zone.points, thickness = zone.thickness })`

**จุด**:

เลือกรูปแบบแล้วกด **คัดลอกทั้งหมด** ได้ข้อความเยื้อง 4 ช่อง มี comma ท้ายบรรทัด วางลงใน table ของ config ได้เลย

| ตัวเลือก | ผลลัพธ์ต่อ 1 จุด |
|---|---|
| vec3 | `vec3(195.17, -933.77, 30.69),` |
| vec4 | `vec4(195.17, -933.77, 30.69, 144.50),` |
| + ใส่รัศมี | `{ coords = vec3(...), radius = 2.00 },` |
| + ใส่ชื่อ | `{ label = 'ชื่อ', coords = vec3(...), radius = 2.00 },` (จุดที่ไม่มีชื่อจะไม่มี `label`) |
| + ใส่โมเดล | ``{ coords = vec3(...), model = `prop_bench_01a` },`` (เฉพาะจุดที่มี prop) |
| + ใส่ marker | `{ coords = vec3(...), marker = { size = vec3(1.50, 1.50, 0.50), color = { 255, 255, 255, 90 } } },` (ทุกจุด) |
| + ใส่ blip | `{ coords = vec3(...), blip = { sprite = 280, color = 5, scale = 0.80 } },` (เฉพาะจุดที่เปิด blip หรือวงบนแผนที่) |

ใน `blip = { ... }`
- `sprite` และ `scale` มีเฉพาะจุดที่เปิด **Blip**
- `color` มีเสมอ
- `area = true` มีเฉพาะจุดที่เปิด **วงรัศมีบนแผนที่** เช่นเปิดแค่วง จะได้ `blip = { color = 1, area = true }`

ลำดับ field ในแต่ละบรรทัด: `label`, `coords`, `radius`, `marker`, `model`, `blip` ถ้าไม่ได้เลือกอะไรเพิ่มหรือจุดนั้นไม่มีค่าที่เลือก จะได้แค่ `vec3(...)` / `vec4(...)`

`'` และ `\` ในชื่อจะถูก escape ให้เป็น string ของ Lua ที่ถูกต้อง โมเดลออกมาเป็น backtick hash ตามแบบ config ของเรา ตัวเลือกที่เลือกไว้จำไว้ในเครื่อง (localStorage ของ NUI) ค่าเริ่มต้นคือ vec3 + ใส่รัศมี + ใส่โมเดล

**ล้างทั้งหมด** ต้องกดสองครั้ง ลบจุดทุกจุดรวมถึงใน KVP

## Build UI

UI อยู่ใน `ui_src/` (Vite + Svelte 5) build ออกไปที่ `web/build/` ต้อง build ก่อน start resource

```bash
cd ui_src
bun install
bun run build
```

`bun run dev` เปิดหน้าทดสอบที่ `http://localhost:5249` พร้อมข้อมูลตัวอย่าง กด `J` = จำลองการเพิ่มจุด, `` ` `` = เปิดรายการ, `9` = แจ้งเตือนจุดเต็ม, `0` = ล้างรายการ

## NUI contract

Lua → UI (`{ action, payload }`)

| action | payload |
|---|---|
| `hydrate` | `{ scale, locale, keys = { add, menu }, precision, radius = { default, min, max, step }, limit, labelLength, modelLength, blip = { spriteMax, colorMax, scaleMin, scaleMax }, marker = { sizeMin, sizeMax }, poly = { thicknessMin, thicknessMax, limit, vertices }, visible, points, polys }` |
| `open` | `{ keys }` |
| `close` | – |
| `add` | `{ index, point, keys }` |
| `full` | – |
| `visible` | `boolean` |
| `place` | `{ active, target, keys }` เปิด/ปิดโหมดวางด้วยเมาส์ `target` = ลำดับ Poly หรือ 0 = จุด |
| `poly` | `{ index, poly, added }` Poly ที่เปลี่ยนจากฝั่ง Lua (`added` = ลำดับจุดยอดที่เพิ่งวาง หรือ 0) |
| `removed` | `{ indexes }` จุดที่ Lua ลบเอง (ย้อนการวาง) |
| `toast` | `{ key, args }` ข้อความจาก locale `ui` |

`point` = `{ x, y, z, h, r, label, model, blip, sprite, color, scale, area, size = [x, y, z], tint = [r, g, b, a] }`

UI → Lua (ตอบ `1` / `0` ทุกครั้ง)

- `uiReady`, `close`, `clear`
- `select { index }` (0 = ไม่เลือก), `visible { value }`
- `update { index, x, y, z, h, r, label, blip, sprite, color, scale, area, size, tint }`
- `model { index, model }` (`''` = เอา prop ออก)
- `here { index }` และ `ground { index }` ตอบเป็น `point` ที่แก้แล้ว
- `teleport { index }`
- `remove { indexes }` ลบทีละจุดหรือหลายจุดก็ใช้ตัวนี้ (`indexes` = array ของลำดับจุด ห้ามซ้ำ)
- `polyCreate` ตอบ `{ index, poly }` หรือ `0` ถ้าเต็ม
- `polyUpdate { index, label, thickness, color }`, `polyRemove { index }`, `polySelect { index, vertex }` (0 = ไม่เลือก และเป็นเป้าหมายของโหมดเมาส์)
- `polyFlatten { index }` ตอบเป็น `poly` ที่เกลี่ยแล้ว
- `vertexUpdate { index, vertex, x, y, z }`, `vertexRemove { index, vertex }`
- `place { index }` ปิดรายการแล้วเข้าโหมดวางด้วยเมาส์ (`index` = Poly หรือ 0 = จุด)

`poly` = `{ label, thickness, color = [r, g, b, a], points = [{ x, y, z }, ...] }`

KVP `points` เก็บเป็น JSON array ของแถว `[x, y, z, heading, radius, label, model, blip, sprite, color, scale, area, sizeX, sizeY, sizeZ, r, g, b, a]` แถวจากเวอร์ชันก่อนที่มี 6 หรือ 12 ช่องยังโหลดได้ ช่องที่ขาดใช้ค่าเริ่มต้นจาก config

KVP `polys` เก็บแถวละ Poly: `[label, thickness, r, g, b, a, x1, y1, z1, x2, y2, z2, ...]`
